# Third-party software

XR Desk uses the following open-source software. Their licenses apply to them. XR Desk is not affiliated with these projects.

| Software | Used for | License |
|---|---|---|
| [scrcpy](https://github.com/Genymobile/scrcpy) (the server that runs on the phone), Genymobile | reading the phone's screen, sound and sending input | Apache License 2.0 |
| Android platform-tools (`adb`), Google | talking to the phone over USB | Apache License 2.0 (see the platform-tools notice) |
| [Qt 6](https://www.qt.io/) | the windows and the program | LGPL v3 (the Qt libraries are used as shared libraries) |
| [FFmpeg](https://ffmpeg.org/) | decoding picture and sound | LGPL v2.1 or later |

The full license texts are included with the installer, and the source of the LGPL libraries is available from their projects.
