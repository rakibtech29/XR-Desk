# Changelog

All notable changes of XR Desk. Newest first. Versions are `MAJOR.MINOR.PATCH`; every release on GitHub has the tag `vMAJOR.MINOR.PATCH`.

## [3.5.0] - 2026-10-12
First public preview. See [RELEASE_NOTES.md](RELEASE_NOTES.md).

### Added
- Phone screen window (mouse, keyboard, resize, rotation, side bar).
- Multi window: one window per app, with name, icon and taskbar button; Recents cleared when a window closes.
- App window title bar: Sound, Mobile / Desktop mode, Free resize (preview).
- Sound forwarding that is really on / off on the phone; Device Sound switch.
- Main window with phone list, Refresh, Play / Stop and a Logs card.
- Free version: at most 3 app windows for one phone, with a popup.
- Update Check window (checks GitHub Releases, confirms, downloads with progress, verifies SHA-256).
- About and Buy Premium open the author's Telegram page.
- Windows installer (per user).

### Known issues
- Fingerprint / screen-lock prompts cannot be shown in an app window.
- Tested only on Samsung Galaxy A22, Android 13.
